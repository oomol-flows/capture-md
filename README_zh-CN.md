# MD2Image - 让你的文字变成精美图片

只需几秒钟，就能把普通文字变成精美的分享图片。无论是社交媒体发帖、演示文稿，还是任何需要视觉效果的场合，都能轻松搞定。

## 这个工具能做什么

这套工具帮你把普通文字变成惊艳的视觉内容，完全不需要任何设计技能。就像随身携带了一位平面设计师！

### 制作社交媒体爆款内容

**小红书排版器** 自动为你的文字添加吸睛效果：

- 添加抓人眼球的表情符号
- 创建清爽的视觉分隔线
- 突出显示重要的词句
- 优化排版方便手机阅读
- 让你的文字拥有小红书、Instagram等平台上的专业精致感

只需粘贴你的文字，智能排版工具会帮你搞定一切！

### 把文字变成精美图片

**Markdown 转图片** 功能将你的文字转换成漂亮的图片文件：

- **自选风格**：从多种精美背景色中选择（紫色、粉色、蓝色、绿色、日落色等等），或者自定义你喜欢的颜色
- **完美尺寸**：针对不同平台生成合适大小的图片——常规帖子、小红书、朋友圈，或自定义尺寸
- **支持特殊内容**：图片可以包含数学公式、流程图和图表
- **专业字体**：多种字体风格可选，包括专为中文优化的字体
- **卡片式高亮**：添加特别的提示框来强调重要信息
